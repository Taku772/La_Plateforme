![Cybersprint3](./assets/cyber3.jpg)

## Overview of the bootcamp 

The main objective of this bootcamp is to prepare people with the prerequisites to do a training course enter Cybersecurity.

Cybersecurity requires extensive knowledge in networking, programming and simply understanding how a computer works.

This program is built around the hacker mentality, which aims at always improve capabilities, find breaches or bugs and solve problems. The motto being "Where there's a bug, there's a way".

## Requirements

List of minimal requirements for the trainees;

- Motivated
- Self learner
- Problem Solver

## The content of bootcamp

LEARNING: the courses are a set of tutorials, combining theory and practice, in order to quickly gain competence.

PROJECTS: the projects are designed to help you discover, by yourself or in a group, specific code issues. They also serve, of course, to train you on realistic projects.

The content will be split in 5 modules spread over 4 weeks of training:

- [01. System fundamentals](/01-Hardware/)
- [02. netWork and services](/02-Operating_Systems/)
- [03. Scripting and automation](/03-Git/)
- [04. Linux advanced and container orchestration](/03-Git/)
