# Hardware architecture of a computer

In computer science, the term architecture refers to the organization of the elements of a system and the relationships between these elements. The software architecture concerns the organization of the different programs between them. The hardware architecture concerns the organization of the different physical devices present in a computer. In both cases, this organization is based on the principle of decomposition.

In this chapter we will concentrate on the hardware architecture.

## 1.1 Harwarde VS Software

The two concepts Hardware and Software are two different fields. Indeed, hardware refers to the physical hardware constituting the desktop computers, the PC, the external hardware while the software is a software and an application that runs on a computer.

![](https://LaPlateforme-files-production.s3-eu-west-1.amazonaws.com/e12cbd73-91f5-4dc5-a1f0-8c900366ec4a-template.png)


The hardware includes all the components of a computer but also its external peripherals such as USB keys, keyboard, mouse etc ...

Software is immaterial and characterized by sequences of instructions that can be interpreted by a machine. They determine the tasks that can be analyzed and executed by the machine. We can say that software is the intelligent part of a computer. 

## 1.2 Internal VS external devices.

The internal components and the external components.

### 1.2.1 External Devices

Among the external components of a computer, we distinguish output devices (monitor, printer, speakers, CD burner) from input devices (keyboard, mouse, CD/DVD-ROM drive, scanner, microphone, webcam, joystick, digital camera and camcorder). There is a special case: the modem, which is an output device if you send information to the Internet and an input device if you receive information from the Internet.

### 1.2.2 Internal devices

Internal components include everything inside the tower or laptop. They are also divided into several categories:

![](https://LaPlateforme-files-production.s3-eu-west-1.amazonaws.com/5ff62c1d-37cb-40d1-99dc-daeff363a4db-template-(2).png)

#### The processor
The processor is the thinking head of your computer. The more powerful it is, the faster the information is processed! Its computing entities are called cores. There are processors with two, four, six or more cores. Its efficiency also depends on its frequency, expressed in gigahertz (GHz).

There are different models of processors and this technology is evolving rapidly, but there are two brands that predominate on the market, AMD and Intel. 

In the Intel brand for example, we usually see the models:
- Intel Core i3 which corresponds to the entry level of Intel Core processors
- Intel Core i5 which is the mid-range
- Intel Core i7 and Intel Core i9, which are in the upper range 

At AMD, the classification of processors is perhaps a little less obvious. We can still divide them as follows: 
- AMD Athlon which is intended for a general public use.
- AMD RYZEN which is the mid-range.
- AMD RYZEN pro which is the superior range


#### Random Access Memory :
This is the temporary memory of the computer, where all the files the user is working on are stored. **This memory is temporary, because the
information is deleted when the computer is shut down**. The larger this memory, the easier and faster the computer works and the more different tasks it can handle.
The capacity of this memory is expressed in gigabytes (GB). Random access memory comes in the form of in the form of small bars that are inserted into the motherboard. A computer can thus have several memory sticks to have a total of 8 - 16 - 32 GB of RAM or more (depending on the computer).


#### The graphics card :
It is responsible for the display of all graphic elements: games, but also photos, videos and software... You can find graphics cards integrated to the motherboard or dedicated graphics cards. The dedicated graphics cards will be more powerful because they usually have dedicated RAM and in some cases even a dedicated processor. But they are obviously more expensive. 

The graphics card can be more powerful than the processor to perform certain actions such as matrix calculation (used in particular to create 3d images), but also to mine bitcoin or to crack passwords.

#### The hard disk :
The hard disk is the storage space reserved for the user: it holds your documents, programs, data... Its capacity is expressed in gigabytes (GB) or terabytes (TB, 1 TB = 1000 GB). From 300 GB to 2 TB, there are all sizes! It is also possible to add internal SSD hard disks in some computers, or to connect an external one.

#### The motherboard :
The motherboard is the base on which all the elements fit together. It houses all the components of your computer, and determines its possibilities of evolution. Depending on the number of slots it has, you can then add memory bars, change the processor or integrate a graphics card... It also embeds the chips and, responsible for the transmission of information between the components and the computer. It has various additional options, such as Wi-Fi cards, sound...

#### The power supply :
It often goes hand in hand with the PC case. Responsible for the arrival of electric current, it is measured in watts. It comes in the form of a case, and includes fans.
