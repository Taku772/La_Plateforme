## The Mission

Although not well known one of the most efficient way to manage your computer is through the use of a [command line interface](https://en.wikipedia.org/wiki/Command-line_interface) (_CLI_), a **prompt** enabling you to interact with the machine via written **commands specifying actions** to be performed. Both Windows and Linux have access to the CLI but this challenge will focus on making you able to use Linux command line prompts.

To complete this challenge you will have to solve multiple exercises ranging from an interactive web based game introducing the base concepts to a "_Trial of Might_" testing your acquired knowledge. Go through each of the exercises below and make sure you understand before moving on to the next.

1. [Introduction](./assets/exercises/introduction/README.md)
2. [Fundamentals](./assets/exercises/fundamentals/README.md)
3. [Advanced](./assets/exercises/advanced/README.md)
4. [CLI Sherlock](./assets/exercises/cli_sherlock.md)
5. [Trial of Might](./assets/exercises/trial_of_might.md)

For this challenge to be considered done you will also have to provide your coaches (_in the manner they tell you to_) with a list of the passwords for each level of the "_Trial of Might_".

> **NOTE**: A prompt is just a piece of software that interprets the commands you type to the machine, as such there exists many variant called "_shells_"". The most common one is [BASH](https://www.gnu.org/software/bash/) which is based on its predecessor [SH](https://en.wikipedia.org/wiki/Bourne_shell#:~:text=The%20Bourne%20shell%20(%20sh%20)%20is,interpreter%20for%20computer%20operating%20systems.&text=Although%20it%20is%20used%20as,considered%20to%20produce%20structured%20programs.), but you can find plenty of alternative online such as the popular [ZSH](https://www.zsh.org/), or even the modern [Nushell](https://www.nushell.sh/) (_my personal favourite_) and many more. In this training we'll usually assume that your using BASH but feel free to use whatever best fit your needs, you'll most likely need to know how to use more than one anyway.
