# Package Manager

You need to install "_Chromium_" on your machine, to do so you will need of is called a [package manager](https://en.wikipedia.org/wiki/Package_manager). Most Linux distribution come with one installed by default, for example on [Ubuntu](https://ubuntu.com/) it's `apt`. Find out which package manager you have access to then open your **terminal** and **read its manua*l* to understand it, then follow the instructions below:

* update all the packages on you system
* search if your distribution has a package for "_Chromium_"
* install "_Chromium_"
* launch "_Chromium_"
* remove "_Chromium_"

> **INFO**: "There are plenty of package manager across a lot of operating system, Mac uses `brew`, Archlinux uses `pacman`, even languages such as NodeJS (`npm`), Python (`pip`) and PHP (`composer`) use them to manage dependencies. On windows you can use something like `winget`
