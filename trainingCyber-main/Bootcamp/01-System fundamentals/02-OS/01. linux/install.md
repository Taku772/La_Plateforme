## The Mission

2. Bob, who is a user with restricted access. 
He can only read, write and execute files in his ``/home/bob/`` folder.

## Linux 
Linux is an operating system, just like Windows or MacOS X. It allows you to work as you would under Windows. But it works differently.

Some people still see Linux as a horrible system full of complicated commands. This is no longer true. Linux now has a nice, comfortable and easy-to-use graphical system.

We usually say that Linux is an operating system. In reality, Linux is only the core (the "kernel") of the GNU/Linux operating system.
(Microsoft's Windows NT, 2000 and XP operating systems also have a kernel, but a different one: the NT kernel.)

The kernel takes care of all the dirty work: memory management, access to peripherals (hard disk, CD-ROM drive, keyboard, mouse, graphics card...), network management, sharing of CPU time between programs (multi-tasking), etc.

Unlike Windows, whose graphical interface is imposed on you, there are different graphical interfaces under Linux, the main ones being Gnome, KDE and XFCE. It is even possible to run Linux without a graphical interface, or even to launch the graphical interface only when you want.
