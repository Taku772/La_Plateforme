# LaPlateforme - Environment setup

Type of challenge: **learning** </br>
Competency: **is able to setup a working environment** </br>
Module: **getting started** </br>
Duration: **4 hours** </br>
Team challenge :  **solo** </br>

## The mission

Time for serious things to begin, right !? Well before we get too hasty, you need to make sure that you have a good **working environment** to tackle the challenges to come.

At _LaPlateforme_ we believe that everyone should be able to use the software they want, as long as it **gets the job done**. As such you are free to choose your main OS whether it's _Linux_, _Windows_ or whatever else. However **there is a limit** to our flexibility as your working environment must meet some minimum requirements. 

They are as follow:

* Have access to [virtual machines](https://en.wikipedia.org/wiki/Virtual_machine) as we'll use both **Linux** and **Windows**.
* Have access to a [terminal emulator](https://en.wikipedia.org/wiki/Terminal_emulator).
* Have a **text editor** or **IDE** installed. ie : [Atom Editor](https://flight-manual.atom.io/getting-started/sections/installing-atom/) and [VScode](https://vscode.pro/install-vscode)
* Have access to internet and a browser (_duh_).
* Have _Discord_ installed or at least available on the web version.
* Have `git` setup.

This challenge is all about having you **setup that base environment** with your own touch. Try to **craft your perfect workspace** while respecting the requirement above. To do so you can even explore options such as [dual boots](https://en.wikipedia.org/wiki/Multi-booting), virtual machines or even the [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) (_Windows Subsystem for Linux_)!

To help you with your task, follow the instructions below:

* Choose and install (_if needed_) your main OS (_operating system_).
* Install Discord and connect to it (_so that you can ask for help_). [Invite](https://discord.gg/yU9DRDVj)
* Install a [virtual machine hypervisor](https://www.vmware.com/topics/glossary/content/hypervisor), we strongly recommend [VMware Player](https://www.vmware.com/be/products/workstation-player.html) (_at least to start_). Easy Alternative : [Virtual Box](https://www.wikihow.com/Install-VirtualBox)
* Research and choose a text editor.
* Install git and [set it up](https://git-scm.com/book/en/v2/Getting-Started-First-Time-Git-Setup).

> **NOTE**: You can optionally install [TeamViewer](https://www.teamviewer.com/en/), but it will only be used as **last resort** and for **extreme cases**.
